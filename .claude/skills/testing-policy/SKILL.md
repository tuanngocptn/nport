# Testing policy

`docs/TESTING.md` is the specification — tiers, what must be integration rather than unit, how golden fixtures are captured and reviewed. **This file does not restate it.** It answers one question the spec deliberately leaves to the author: *given what I just changed, what test do I owe?*

Enforced by `.claude/hooks/require-tests.sh`, a `Stop` hook. It blocks once per unique set of untested areas, so a legitimate exception costs one message rather than a loop.

**Tests are written by the `test-writer` subagent, which is pinned to Sonnet** (ADR-0023). Delegate to it rather than writing tests inline. Give it the specific change to cover — the files, the behaviour, and what already broke once — because it does not inherit this conversation's context and a vague brief produces vague tests.

## What each area owes

| Changed | Required | Non-negotiable because |
| --- | --- | --- |
| `apps/api/src/**` | Vitest in `apps/api/test/`, with `@cloudflare/vitest-pool-workers` for anything touching Durable Object storage, alarms, or bindings | The whole lease design rests on single-threaded DO execution and at-least-once alarms. A mocked DO passes precisely when those assumptions are wrong |
| `apps/web/src/**` | Playwright in `apps/web/e2e/` — behavioural assertion plus a visual snapshot (ADR-0023) | The site is the product's front door and has no other test tier |
| `apps/desktop/src/**` | A test under `apps/desktop/e2e/` | Phase 4; see ADR-0023 on why this is WebdriverIO rather than Playwright |
| `apps/desktop/src-tauri/src/**` | Inline `#[cfg(test)]`, or `tests/` | It links `crates/core` in-process, so a panic here kills the GUI |
| `crates/protocol/src/**` | Inline `#[cfg(test)]`, **plus** an `insta` snapshot and a golden fixture for any wire-format change | An encoder that agrees only with itself proves nothing |
| `crates/core/src/**`, `crates/cli/src/**` | Inline `#[cfg(test)]`, or `tests/` | — |
| `packages/*/src/**` | A colocated `*.test.ts` | — |

Never required: `crates/contract/**` and `schema/*.json` (generated), `crates/xtask/**` (repo automation), `**/examples/**` (the Phase 1 spike is throwaway by design), vendored files (`*.capnp`, `*.pem`), `build.rs`, and anything `docs/TESTING.md` lists as deliberately untested.

## Five traps this repo has already hit

1. **Golden fixtures come from cloudflared, never from our own encoder.** A fixture generated by the code under test asserts only self-consistency.
2. **Live-edge tests are `#[ignore]`.** `cargo test` stays hermetic and offline. They also need a `Drop` guard for cleanup — a panic mid-test otherwise leaks a real lease until expiry.
3. **A test must assert credential material does not leak.** `crates/protocol/src/token.rs` has the pattern: a table of malformed inputs, asserting no error message echoes any part of the token. Errors get logged by definition, so this is the leak path that matters.
4. **Constants copied from upstream need a test that they are usable here, not just correct.** `MAX_INCOMING_STREAMS` was faithful to cloudflared and wedged the process; it now carries a compile-time assertion. Fidelity to the wire is not the same as fidelity to the Go source.
5. **Test names state what they assert.** `rejects_subdomain_with_trailing_hyphen`, not `test_subdomain_2`.

## When the hook blocks

Two valid responses, and no third:

- **Delegate to `test-writer`.** Default. The table above says which tier; pass that to the agent along with the change.
- **State the exception explicitly**, naming which of the "never required" cases applies or which `docs/TESTING.md` exclusion covers it. A rename, a comment, a vendored file update.

Do not satisfy the hook by touching a test file without adding coverage. It checks that a test artifact changed, which is a proxy; defeating the proxy while leaving the behaviour untested is worse than the hook not existing, because the next reader will trust it.

If a change reveals that the policy itself is wrong for a whole class of work, that is an ADR in `docs/DECISIONS.md` plus an edit to this file — not a one-off bypass.
